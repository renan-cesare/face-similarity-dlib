# Security Policy

## Supported Versions

This repository is provided as a portfolio/study reference.
Security updates may be applied when relevant.

## Reporting a Vulnerability

If you discover a security issue, please avoid opening a public issue with sensitive details.

Instead, report it privately by contacting the repository owner.

## Data & privacy notes

- Do not commit credentials, personal data, face datasets, or exported assets.
- This project processes biometric-like data (face embeddings). Use only authorized data and environments.
