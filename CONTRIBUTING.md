# Contributing

Thanks for your interest in this repository.

This project is primarily intended as a **portfolio and study reference** for face embeddings
(dlib + OpenCV). Contributions are welcome, as long as they keep the scope simple and safe.

## Guidelines

- Keep changes small and focused.
- Do not add real personal data, face datasets, exported images, or any sensitive content.
- Do not commit `.dat` model files (they should remain local).
- Prefer documentation improvements, safety notes, and small refactors.

## How to contribute

1. Fork the repository
2. Create a branch (e.g., `docs/readme-fix`)
3. Open a pull request describing what changed and why

By contributing, you agree that your contributions will be licensed under the MIT License.
